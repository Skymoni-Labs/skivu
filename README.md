# Skivu

独立开发的 Flutter Android 聊天应用，提供多模型文字对话、液态玻璃界面、角色卡与外观配置。同一套源码支持 Web 手机界面预览。

当前版本 **0.2.5+9**，Android 24+，完整 Flutter ABI 为 arm64-v8a / x86_64。安装名、图标与应用内品牌为 Skivu；包标识保留 `com.skyjjgw.independent.ski`，覆盖升级保留已有数据。

## 已实现

- App 内直接使用 Skymoni 普通账号/密码登录；按站点策略处理 RSA 加密、TOTP/备用码。需要 Passkey/网页验证码时保留浏览器额外验证入口，不跳过账号保护。
- 自动同步可用模型、站内钱包/订阅与独立内测计划。申请保留网页入口，资格与额度由管理员控制；批准账号可直接使用内测额度，不要求设备配对、不在不足时改扣钱包。
- 输入框直接搜索选择模型和资金来源，旁边提供回复长度、流式、角色卡与显示偏好；自定义连接可设置温度、上下文和超时。
- OpenAI 兼容 Chat Completions、Responses、Claude Messages、Gemini Generate Content；流式/非流式、多轮历史、停止/重试、草稿和本地恢复。流式文字按字素逐帧呈现，平滑处理成批回包；停止保留已收到的内容，回看历史后可一键回到最新消息。
- 点击对话头像编辑角色描述、性格、场景、关系、示例对话、开场白与回复边界，并可选择本机图片作为角色头像；头像缩至 256px、去除原图元数据，随本机角色备份保存，不进入模型提示词。自己的头像可编辑用户身份卡，设定实际用于之后的模型请求。
- 深色文字、玻璃气泡、圆矩形/直角/尾角/柔和圆角，主题/字体/图片和视频背景、模糊与透明度、命名外观方案。设置采用紧凑分组，语音与模型连接分别管理。
- 覆盖式折射胶囊顶栏，可切换覆盖状态栏的全宽玻璃长方形；生成时显示“对方正在输入中”。思考过程位于回复气泡上方，以透明展开入口显示；顶栏高度收紧，平面玻璃顶栏不绘制白色边框。长回复保留右侧空隙；Android 静态壁纸先独立采样并生成模糊位图，避免拖动长回复时玻璃忽清忽糊；视频背景保留实时采样。底部实际统计可关闭，开启时保持一行、无独立白底。
- 账号页顶部可直接退出并登录另一账号；本机离线也能退出，退出期间迟到的同步结果不会恢复旧账号。只撤销本次会话，不踢下其他设备。
- 角色直接作为左侧文件夹，展开显示独立对话及数量；全局新建先选角色，文件夹内直接新建。共享角色卡，聊天记录、上下文与草稿分别保存。支持角色/标题搜索、重命名、置顶、确认删除，以及重启恢复归属、选择和展开状态；旧版未保存逐对话归属的记录沿用原全局角色，不丢弃聊天。
- 原创多圈消息导航拨盘、搜索/收藏定位；历史与回到最新按钮随输入框高度排列在其上方右侧，两个玻璃圆钮大小一致；长按时的消息预览位于刻度盘上方，避免重叠。左右侧栏保留跟手与弹簧吸附。
- 迁入作者旧项目自行新增的通话界面与水滴光球，适配当前聊天和 Android 系统识别，支持字幕、静音、打断、挂断。语音合成可选系统、OpenAI 兼容、ElevenLabs、Azure 或自定义 HTTP，管理连接/音色/语速与试听；自定义支持 GET/POST、JSON 模板及直接音频、Base64、Hex、音频 URL。完整配置存于本机安全存储，云端语音按所选服务账号计费。系统语音可能联网，需要本机服务及语言包；没有打包旧工程的离线模型或权重。
- 通过服务器转发 APK 的应用内更新，验证摘要、大小、包名、递增版本与同签名，再交由 Android 系统确认安装。

附件、插件运行和右侧文件/工具/浏览器/终端统一显示“即将开放”，不提供假文件或假执行。统计缺少服务端数据时显示 `—`。

## 运行与构建

开发基线 Flutter **3.41.9** / Dart **3.11.5**，Android 需要 Android SDK 与 JDK 17。

```sh
git clone https://github.com/skyjjgw/skivu.git
cd skivu
flutter pub get
flutter run -d <android-device-id>
# Web 手机预览
flutter run -d chrome
# Android release
flutter build apk --release --target-platform android-arm64,android-x64
```

在“设置 → 中转站账号”登录自己的账号，也可在“模型与服务”使用自己的连接。仓库不提供密码、API Key 或付费额度；密钥和会话通过 `flutter_secure_storage` 单独保存，不包含在聊天备份中。Web 直连接口取决于服务端 CORS，手机和浏览器的数据分别保存。

已分发 APK 当前沿用开发证书，便于覆盖既有测试安装，不代表正式生产签名；不同开发者的调试证书不能彼此覆盖。旧硬件 BetaDevice 通道与新的账号资格内测通道分别控制，不能把开发证书当作正式硬件证明信任。

Windows 辅助脚本中的本机路径可按环境调整；上述 Flutter 命令不依赖这些脚本。安装包与对应源码见 [Releases](https://github.com/skyjjgw/skivu/releases)。

## 验证与范围

```sh
flutter analyze
flutter test
```

当前 126 项全套检查通过，新增覆盖流式字素/停止前缀、语音协议/安全存储/取消晚回包、键盘下的语音编辑与消息导航；并覆盖协议增量响应、错误/取消/重试、多轮/存储、密码与会话分离、原生登录与 MFA 契约、内测资金隔离和撤销、角色卡实际请求与备份、通话迟到结果、侧栏与移动布局，以及滚动玻璃像素回归、头像规范化、离线退出与同步竞态。

0.2.5 追加刻度盘/预览不重叠、窄屏放大字体及两个导航按钮等尺寸检查。0.2.4 新增角色与对话归属迁移、独立上下文请求、菜单与搜索、窄屏布局及定位按钮检查；安卓模拟器实测新建角色对话选择、重命名/置顶、搜索与冷启动恢复。

生产接口已用零额度专用账号实测 App 内登录、模型同步/切换、未开通内测阻断和退出；0.2.1 已追加两个独立账号的连续登录、同步与换号退出，均未发付费模型请求。0.2.3 用本地测试服务通过原生网络层验证成批 SSE 回复及音频合成到 Android 播放器/完成回调，验证语音配置冷启动恢复；这些是协议与流程验收，不代表每家云端声音服务均已付费实测。0.2.2 在 PKJ110 实体手机的 Vulkan 渲染下复现并修复了拖动长气泡时模糊切换，用户已确认稳定；同时检查键盘弹出/收起后的背景对齐。像素回归覆盖高频纹理、屏幕边缘和拖动中的固定背景采样；不将此结论扩大到视频背景和所有设备。Android 已实际验证头像选图/保存/重启恢复、壁纸下的滚动玻璃、非胶囊顶栏延伸，以及本地测试服务的流式回复、思考区域和正在输入提示。已检查模拟器系统语音权限、收音入口、试听回调和挂断，实体手机完整语音对话仍取决于实际语音服务和声音环境。此前普通接口的两轮文字聊天、上下文和冷启动恢复已验收，不将这些范围扩大成所有厂商/模型均已实测。
