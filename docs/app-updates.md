# 应用内软件更新

从“设置 → 检查更新”进入独立全屏页面。页面使用独立生成的静态星空与低频流星（见 [背景来源](update-sky-provenance.md)）、半透明玻璃卡片和固定顶部导航。底部仅悬浮胶囊按钮与柔和渐暗遮罩，内容可从其后方滚过；滚动尾部会根据实际按钮高度留出余量，保证小屏及较大字体下能完整读到最后一行。

版本号、安装包大小与更新说明优先读取已验证的服务器发布信息。没有可用更新时显示当前安装版本及 Android 已安装 APK 的真实字节数（拆分安装时合计所有 APK）；无法取得大小时明确显示暂不可用，不猜测包大小。与源码版本一致时显示随包附带的说明。未知版本不会套用其他版本的更新文案。

底部按钮按真实状态切换为检查、下载进度、下载或安装。下载可以取消，只有通过完整性校验的下载才可进入安装步骤。下载和安装为两个明确的用户操作，安卓仍会要求确认安装。“更多”提供重新检查和版本信息。

现有更新通道保持不变：HTTPS 同源目录、设备 ABI/SDK、应用标识、版本递增、SHA-256 和签名校验。页面没有宣称断点续传、安装后自动清理、后台系统优化或不存在的社区入口。

`test/app_updates_page_test.dart` 覆盖折叠/返回、窄屏大字长说明、固定操作区、下载/取消/安装状态与失败重试；`test/app_updates_test.dart` 覆盖更新元数据及下载/安装校验。
