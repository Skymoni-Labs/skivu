# 插件内滑动与界面控制

0.2.35 起微信和 QQ 页面全部由 Flutter 绘制。宿主 SlideDeck 在插件路由上关闭横向拖动，插件内部使用 PageView；不再有网页 viewport、iframe 或 WebView 输入框。系统键盘由宿主 Scaffold 统一避让，页面不重复扣除键盘高度。手指捏合不会缩放整个界面，字体和外观仍通过 App 设置调整。

- 微信首页依次为微信、通讯录、发现、我；QQ 为消息、频道、联系人、动态。水平卡片随手指移动，松手由 PageView 吸附，首尾不循环；底部点击使用 260ms 横向过渡，减少动态效果时直接到位。
- 各根页面保留滚动位置。聊天进入信息、搜索等子页时保留聊天组件，返回不会丢草稿或跳到最新消息；隐藏聊天不记录已读。
- 聊天内容区向右滑超过64逻辑像素返回内部上级，向左不更换对话。输入框与媒体操作保留自身横向手势；上下滚动、长按消息和文字选择继续使用 Flutter 的手势仲裁。
- 右侧中部24×144逻辑像素以内的一小段为隐藏界面控制入口。向内拉超过44像素且水平方向明显时显示玻璃竖窗。这段手势不触发卡片切页或聊天返回，上下滚动仍传给内容。
- 竖窗可返回原版或收起，普通模式闲置4秒收起；无障碍导航时由用户主动收起。返回原版保留选中对话与草稿。
- Android29及以上仅为小段入口申请系统返回手势排除区，退出时按实例释放。系统返回先关闭宿主侧栏，再沿插件内部页面栈返回。

Flutter widget 测试覆盖卡片跟手、页序、返回、读状态与草稿；模拟器检查完整键盘、长记录、横滑与隐藏控制。legacy/ 中的历史 JavaScript 测试仅验证归档原型，不作为当前 Flutter 页面验收依据。
