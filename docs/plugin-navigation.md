# 插件内滑动与界面控制

微信、QQ插件的聊天区与宿主左右侧栏分开处理手势。宿主 SlideDeck 在插件聊天路由上关闭横向拖动，HTML原型里的旧侧栏触摸监听在宿主模式下也不执行。原版的侧栏物理效果与明确点击导航入口继续保留。

微信、QQ的整个网页视口固定为1倍，原生WebView关闭手势缩放，页面也声明固定viewport并仅允许横向/纵向平移。双指或双击不会放大整个插件界面，以免visualViewport缩放后与宿主键盘高度错位；正常列表滚动、横向卡片翻页和App设置中的字体/界面大小继续保留。

- 微信首页左右滑动依次切换微信、通讯录、发现、我；QQ按消息、频道、联系人、动态切换。到首尾不会循环跳页。
- 微信四个主页面采用水平卡片翻页：拖动时当前页与相邻页一起跟手，松手后260ms吸附；不足64px回弹，首尾阻尼回弹，不会松手瞬间替换页面。底部标签点击同样横向过渡，连续点击仅排队最后选择，每页保留本次打开期间的滚动位置。系统减少动态效果时取消收尾动画，保留直接拖动反馈。
- 卡片快照仅在翻页期间存在，去除重复ID、禁止交互和无障碍焦点；原始页面及宿主数据不搬动。普通数据刷新不打断翻页，切角色/模式、进入其他页面或视口变化时取消过渡；横拖取消和短滑也拦截误点击，避免意外打开聊天。
- 聊天中向右滑返回插件内部上级页面，不切换到另一位角色、不退出App。聊天中向左滑不更换对话。
- 先判定方向再切换：明显水平位移达64逻辑像素才切换；先开始的上下滚动、斜向滚动、多指、取消、深层表单、媒体/表情工具面板和代码块均保留原有行为。
- 右侧中部24×144逻辑像素以内的一小段为隐藏界面控制入口。向内拉超过44像素且水平方向明显时，显示玻璃竖向小窗。没有常驻手柄或遮挡；上下滚动仍传给网页。
- 小窗可返回原版或主动收起，普通模式闲置4秒自动收起；无障碍导航时由用户主动收起。切换保留选中对话与草稿，不发送内容。
- Android29及以上仅为这小段手动入口申请系统返回手势排除区，原生限制宽度32dp、高度200dp以内。退出插件/页面后按所属实例释放；其他边缘的系统返回行为保持可用。

验证：Flutter测试覆盖宿主禁止拖出、保留原有侧栏动画、隐藏/拉出/自动收起、透传滚动、明确退出及键盘变化后的区域释放；Node测试执行实际JS监听，检查方向锁、页序、嵌套控件、角色切换和旧原型监听的隔离。
