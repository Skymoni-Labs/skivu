# Skivu 主体模块本地体验版

当前版本 0.2.80（84）。本轮直接扩展 Skivu 主体，没有增加小手机插件，没有重构现有插件体系。仅供 USB 手机本地验收，不发布 GitHub、官网、更新目录或插件市场。

Skymoni 玻璃统一为同一条 Flutter GPU 光学管线。沿用 Skymoni GlassLensRenderer 的 SDF、逆幂折射、色散、饱和度、介质染色和双向高光，以及原桥接使用的模糊、厚度、光源、透明度参数；静止、触摸、滚动、惯性与侧栏移动始终使用同一个光学层和前景。不再切换 Android Platform View，不再创建原生镜片/1×1 锚点或做整屏 ImageReader 交接；旧的 Dart/Kotlin 渲染桥接及切换门已移除。35 个上游源码文件和 MIT 许可保留作算法来源参考。

外阴影在光学层之后绘制，且仅限玻璃轮廓外侧，避免实心 BoxShadow 被玻璃采样成内部灰色衬层。普通点击、按住、手抖、边界拖动和真实滚动均不改变材质类型或明暗参数。滚动活动仅用于可选的本地 QA 帧记录，不再决定玻璃后端或通知整页重建。

消息文字和媒体置于独立 RepaintBoundary，保留字形/图片绘制；气泡背景仍按场景坐标采样并随滚动更新，不缓存整个气泡导致背景错位。显示/隐藏历史按钮改为局部通知，从首次开始拖动到持续滚动均不因导航提示重建整个聊天页。普通包关闭帧日志与滚动采样入口；仅本地 QA 编译参数 SKIVU_FRAME_DIAGNOSTICS / SKIVU_SCROLL_BENCHMARK 可启用。采样使用既有对话，不生成或修改消息。

侧栏参考本机 Operit 原版及 Operit2 的保留图层思路：主页面、左右面板持续挂载，Flow 在绘制阶段更新平移，不再逐帧通过 Positioned 布局或执行透视折叠。隐藏侧栏不绘制、不接收触摸或焦点、不参与无障碍导航，内部动画暂停；原页面与面板尺寸保持。侧滑也使用统一光学层，不再交接原生镜片。保留 86% 主页面位移、14% 半透明叠放、原玻璃参数、接触阴影、短滑阈值和阻尼回弹。

连续滚动的历史按钮显示/隐藏通过局部通知更新；停止滚动后再启动隐藏计时，当前消息的布局定位延后到长按历史入口时计算。统一着色器和渲染对象持续复用，相同参数不重复标脏，恒定模糊滤镜复用。可通过编译参数 SKIVU_DRAWER_DIAGNOSTICS=true 记录仅含动画区间和帧耗时的本地日志；普通安装包默认关闭，不记录对话内容、不传输数据。

底部「小云」入口使用与其他导航一致的 21 dp 镂空云朵图标，跟随导航的主题色和选中状态。

设置、角色、世界观、表情包、插件及其他共用主顶栏的页面统一让滚动层铺满全屏，包括状态栏背后及底部手势区。按用户最新要求撤销安全区对滚动视口的裁切，顶栏、状态栏和底部留白仅放在滚动内容起点和末尾；控件初始位置保持，滑动内容可以经过真实玻璃背后。顶栏完整区域拦截点击，防止图标间隙点到下方隐藏选项。共用原顶栏折射参数和开关，侧栏、卡片等材质范围保持。

设置详情页的「所有设置」返回入口改为带浅色底、细边框和圆角的独立按钮，保留返回设置首页的原行为。

外观设置重新排版为「主题、背景、气泡、玻璃、显示」五个等宽分类入口。具体选项按用途分组到独立卡片，统一边距、标题和说明文字；效果预览、分区字体颜色、外观方案默认折叠。预览仍使用实际文字与玻璃参数，设置控件使用独立的可读配色，避免用户选白色主题或复杂壁纸时看不清设置。仅调整设置界面布局与控件样式，已有偏好、云端壁纸选择、玻璃实现和插件体系保留。

外观设置中的「云端壁纸」共用 Skymoni 现有 `https://skymoni.com/api/app-wallpapers` 目录。两个 App 只同步公开壁纸列表，各自保存所选背景，不上传选择或改动账号设置。支持刷新、缓存列表、预览、下载后离线使用；下载校验大小与 SHA-256，图片尺寸按宿主限制适配。失败或取消保留原背景，切换仅由「使用这张壁纸」确认触发，不自动改文字配色。现有服务器、管理工作室和数据目录保持。

Skymoni 材质严格限定在顶部栏，以及底部输入框和模块导航。通用玻璃组件默认使用原材质；左右侧栏恢复原 LiquidGlassLens、独立模糊/透明度、原高光、折射边缘和接触阴影，其他卡片、按钮和弹层恢复原材质。短滑收放保留，侧栏与主页面恢复原半透明重叠关系。设置页的顶栏/输入框预览对应这两个区域。

侧栏按本次手势的方向和位移判断收放：通常短滑约 48 dp 或小幅快速甩动即可，展开与关闭对称，取消回到原状态。玻璃运动通知只让同一着色器更新坐标，不逐帧重建镜片及其文字、按钮。

侧栏展开、拖动、回弹和归位保持同一 Flutter 画面及同一光学层。输入文字、按钮等前景不会因运动状态重新挂载。接缝使用独立的渐变接触阴影，不在折射层中叠加 multiply 阴影；保留原半透明重叠。

侧栏压在主页面上方的原始重叠区域：主页面跟随侧栏位移的 86%，另 14% 在侧栏原玻璃下叠放，形成半透明层次和接触阴影。阻尼回弹、遮罩和侧栏宽度保留；运动阶段改为保留图层平移，避免透视离屏绘制。

底部导航按 Skymoni `src/components/glass-navigation.tsx` 原始参数适配：外栏高 56 dp / 圆角 29 dp，轨道四边留白 4 dp，选中镜片高 48 dp / 圆角 25 dp，宽度为 (导航宽 - 8) / 5。按用户最新要求，导航与输入框共用外层的水平边距和可用宽度，取消导航独立的 344 dp 上限与二次内缩，使两块左右边缘及中心线对齐；高度和 8 dp 分隔保持。21 dp 图标、9/12 dp 标签、原弹簧及 280ms 横向回弹保留；取消额外的按压缩放和选中文字混色。模块名称、主题色和原背景继续使用 Skivu。

按用户最新要求取消选中胶囊的额外白色填充，只保留玻璃镜片、边缘和当前主题强调色的图标/文字。镜片前景布局保持完整范围，避免无子节点的装饰层在玻璃 Stack 中收缩至零尺寸。

输入框与底部导航为两块独立悬浮组件，中间保留 8 dp 背景间隙（关闭用量统计时）；二者仍各有独立玻璃边缘。「对话」显示原聊天与输入框；「今天、任务、记忆、小云」各自显示模块内容，只保留底部导航。从其他页面带入想法时返回原对话并追加到草稿，等待用户发送。原角色、模型、鉴权、插件运行分支、聊天记录、发送确认和草稿保留。

玻璃选择仍有独立的 Skymoni 开关，原玻璃样式开关、参数和侧栏材质保留。Skymoni 光学算法统一由 Flutter GPU 着色器执行，不再用原生视图桥接。35 个原始上游源码/资源仍位于 android/skymoni_glass，UPSTREAM.json 逐文件记录 SHA，MIT 许可和着色器适配归属保留。

按用户最新要求，默认星空实验及强制配色已撤销。继续使用原有自定义图片/视频和原默认背景；之前选星空的临时标记不再影响背景选择。拒绝的星空图仅在本机 ops 历史目录归档，不随包提供。取消额外实色衬层、底部白色统计条和选中镜片的重复描边。镜片只叠加 Skymoni 原有的轻微渐变与细边缘。

新材质下，消息滚动层延伸到输入框背后，镜片读取真实背景。滚动列表仍按输入面板实测高度保留底部空间，最新消息可以完整移到输入框上方。

引用采用约 24 dp 高的小圆角标签，位于输入框内，与正文起点对齐。添加引用不覆盖原草稿；点击可查看原文快照、定位或移除。引用按会话保存，使用稳定消息 ID，发送时原文作为用户上下文附在该条请求中，界面只显示小标签。失败发送保留引用，不带引用的其他发送入口不清空它。

历史入口保留右侧小按钮。短按不展开；长按才出现侧边刻度尺和消息预览。上下拖动选择，向左移动可扩大浏览范围，边缘停留可继续浏览；松开定位，取消不跳转。结束后刻度尺立即收起。历史只加载轻量本机预览，长记录仍懒加载，不因浏览把全部消息部件展开。

个人模块数据使用独立本机键 skivu.main.personal-space.v1。任务、记忆写入串行保存，软删除后可从小云回收站恢复。未自动读取旧聊天，不生成虚假健康数据；任务定时列表当前不发送系统后台通知。

错误安装的 org.skivu.daily-space 已在此前卸载，旧包不再分发；DSH 和既有插件保留。旧 Skymoni 工作树保持原状，统一 GPU 实现沿用其上游光学算法和许可。安装包、校验和实机记录位于 E:/zzz/ops/skivu-main-modules-20261106，当前交接以最新版本记录为准。
