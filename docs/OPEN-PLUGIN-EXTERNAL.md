# 通用外部链接能力（Skivu 0.2.39 / build43）

开放SDK1.0新增 `ui.openExternal({url})`，需要独立的 `external.open` 权限，方法由 `host.info` 返回。任何插件均可按能力探测使用，不检查插件ID、renderer或第三方软件包名。

宿主只接受公开HTTPS地址，拒绝账号信息、控制字符、片段、任意intent、file/data/javascript与本机地址；确认前后检查全部IPv4/IPv6解析结果，并拒绝宿主服务器目标。每次打开均显示真实宿主确认，再由Android ACTION_VIEW委托系统浏览器或关联软件。不发送宿主认证信息，不读取外部软件登录状态或Cookie。

结果 `{status:'accepted'}` 仅表示系统接受打开；`cancelled` 是用户取消，`not_available` 是没有处理程序。业务成功须由相应授权平台提供独立回执。外部浏览器自行处理后续DNS、跳转及自己的账号；本接口不把插件网络代理的地址固定机制扩展到外部软件。

插件页面仍然只加载包内资源，远程脚本、任意套接字、宿主令牌/后台配置和绕过模型发布保护均未开放。第三方插件业务不进入App。

验证：404项Flutter测试（含7项外部链接权限/URL/DNS地址/取消/生命周期/结果用例）、5项JS SDK测试及相关静态分析通过。正式APK为0.2.39+43，保留原签名、包名与3种ABI。Android实际宿主与真实公开服务验收收据随发布交接另行记录；不使用浏览器mock结果替代平台登录或真实业务完成。

同时修复旧HTTPS代理自定义Socket工厂没有进行TLS握手的问题。生产连接先连接已验证固定IP，再通过SecureSocket.secure(host:原域名)完成TLS，保留系统CA、原域名证书与SNI校验；不允许坏证书、不重新解析目标、不跟随重定向。5项本机TLS回归覆盖受信主机成功、主机名不匹配拒绝、不受信证书拒绝、IOClient的HTTP companion保持工作及握手取消关闭。证书/测试私钥由OpenSSL在临时目录生成并删除，不进源码包或生产配置；测试机需提供OpenSSL（可设OPENSSL_BIN）。

新版官方目录为 apps-v2.json，首次启动自动迁移旧官方URL且保留第三方目录，GitHub备用路径同时切换。旧 apps.json 的服务端及GitHub副本保留初版客户端可识别的1.2.0小手机与实验室。新版逐条隔离未知权限/异常条目并提示，单个条目不会隐藏其他有效插件。两个目录协议仍为3.0，安装包摘要、字节数与manifest校验不变。

新增条目隔离、无效目录头、目录迁移3项用例；全量407项Flutter、5项SDK测试与相关静态分析通过。0.2.39 / build43的公开Release保留，没有激活到App更新目录；正式激活版本为0.2.40 / build44。生成测试证书不进入公开仓库。第三方业务继续独立发布。
