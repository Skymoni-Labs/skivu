# 通用外部链接能力（Skivu 0.2.39 / build43）

开放SDK1.0新增 `ui.openExternal({url})`，需要独立的 `external.open` 权限，方法由 `host.info` 返回。任何插件均可按能力探测使用，不检查插件ID、renderer或第三方软件包名。

宿主只接受公开HTTPS地址，拒绝账号信息、控制字符、片段、任意intent、file/data/javascript与本机地址；确认前后检查全部IPv4/IPv6解析结果，并拒绝宿主服务器目标。每次打开均显示真实宿主确认，再由Android ACTION_VIEW委托系统浏览器或关联软件。不发送宿主认证信息，不读取外部软件登录状态或Cookie。

结果 `{status:'accepted'}` 仅表示系统接受打开；`cancelled` 是用户取消，`not_available` 是没有处理程序。业务成功须由相应授权平台提供独立回执。外部浏览器自行处理后续DNS、跳转及自己的账号；本接口不把插件网络代理的地址固定机制扩展到外部软件。

插件页面仍然只加载包内资源，远程脚本、任意套接字、宿主令牌/后台配置和绕过模型发布保护均未开放。第三方插件业务不进入App。

验证：399项Flutter测试（含7项外部链接权限/URL/DNS地址/取消/生命周期/结果用例）、5项JS SDK测试及相关静态分析通过。正式APK为0.2.39+43，保留原签名、包名与3种ABI。Android实际宿主与真实公开服务验收收据随发布交接另行记录；不使用浏览器mock结果替代平台登录或真实业务完成。
