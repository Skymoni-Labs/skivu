# 小云统一执行：限制清单和验收记录

本记录对应 2026-11-09 的完整需求及 11-10 的补充指示。后续实现和安装均在 Android 模拟器上完成；手机 USB 已由用户断开，不将本轮模拟器结果称为真机验收。生产服务没有部署、重启或业务配置变更。历史实测、单元测试、受控 HTTP 回复和真实模型结果分开记录。

## 默认行为与用户配置

- 模型输出 0 表示跟随上游，在允许省略的协议中不发送 `max_tokens`；显式正数按用户配置发送，没有统一 2048/4096/131072 封顶。
- 前台和定时任务的调用次数、日预算和时长 0 表示不额外限制。正数预算保留，并显示实际来源。
- 编程进程没有默认总运行时长；资源队列根据实际 CPU、可用内存和用户设置运行。自动模式中 Linux/Android 程序参考每项 64 MiB，定时运行参考每项 160 MiB；这是并发估算参数，可修改，不是文件或总内存额度。
- MCP 和网络语音合成/识别的超时默认 0，用户可设置正数。取消等待不声称撤销远端已发生的操作。
- 默认最终成果保存到 `Download/Skivu`；用户可选择持久授权目录。读取文件、运行环境生成、公共保存、系统打开和分享分别记账。
- Android 系统识别为默认输入方式，另有自定义 multipart 或 JSON/Base64 服务、密钥、模型、语言、请求头/字段和返回路径。模拟器实际没有系统 ASR 引擎；界面明确提示缺失，不伪造识别结果。

## 界面与执行状态

胶囊水平居中；紧凑小头像、用户展开半身、白点和隐藏沿用同一任务。Android 13+ 采用固定边界透明窗口与内部曲面连续形变，触摸区域按真实胶囊更新，空白区域触摸穿透。展开/收起/中途反向不拆装窗口，不重新执行任务。旧系统保留小窗口回退。竖向位置可保存，测试只重置独立 QA 包位置。

模拟器实际测试覆盖中心误差不超过 1px、反向打断、旋转、三种模式、透明区域点击下方真实控件、截图排除浮岛。头像状态来自执行回执，未知/停止中不提前庆祝。

## 证据与尚未验证的边界

本轮最终 Dart 分析无问题，731 项 Flutter 测试全部通过。原生的 24 项不同验收场景分别通过：4 项手机/浮岛、4 项内容分块、2 项真实网络、14 项任务调度。一次组合运行的 23 项中有 1 项因测试准备只等待 4 秒无障碍绑定而失败；改为等待旧绑定释放及系统实际连接后，手机 4 项重新全部通过。组合失败原日志保留，不写成该次整套通过。13.8 MB SAF 全流程最终通过，14 页全文哈希与源文件、导入结果一致。

详细运行日志在 `E:/zzz/ops/skivu-unified-unrestricted-20261109/WORKLOG.md`，失败尝试及修复前收据保留，不作为成功证据。`emulator-capsule/qa-download-acceptance.json` 和 `qa-npm-acceptance.json` 曾被旧采集器写成缺失文件错误，不能当作成功 JSON；对应真实网络测试日志仍保留，最终使用校验采集器重新采集。

真实模型此前已在原版本手机生成 XLSX/DOCX；本轮大文件、长定时和错误恢复采用受控 HTTP 模型回复加真实 Android/Linux 执行。受控答案测试不等于模型答题质量验证，模拟器无系统 ASR 引擎也不能冒称完成系统语音识别质量验收。未验证的设备/浏览器/OEM/上游参数上限不写为通过。

本轮不会重新引入小云独立闹钟。系统时钟仍沿用现有集成；无障碍 UI 操作可能需要目标应用的可见界面，不能保证所有应用都在后台完成。通用能力由接口、权限和真实 UI 决定，不承诺系统未提供的 Root/后台界面能力。
