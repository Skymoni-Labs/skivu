# 小云、任务与定时（0.2.90）

小云、今天、任务页及定时页共用同一条任务记录。普通查询和临时设备操作不会自动加入任务。用户明确交代待办、后续跟进或定时处理时才保存。

## 任务与结果卡片

- `tasks.create/list/get/update/complete/archive` 提供明确的状态设置、revision 冲突检测和最小原子回执；待完成、进行中、已完成、归档分别表达。
- 手动编辑与小云操作读取同一记录。卡片“查看任务”打开原任务，“交给小云”带入一次任务引用；删除聊天不删除任务或计划。
- 外部操作完成卡片保留“已核验”和“用户确认”的区别。“加入任务”仅保存管理记录与来源关联，不重新设置闹钟或执行原操作。
- 有日期只是截止时间；有时间的旧任务仍显示“未设置提醒”，不会自动启用计划。
- 保持流式输出、思考内容的位置与头像位置。执行详情可展开，任务列表不增加工具运行历史。

## 两种定时安排

**系统提醒**由手机实际日历/时钟负责，没有重新引入小云自建闹钟或精确闹钟权限。

日历通过 Calendar Provider 写入事件及提醒，保留真实外部 ID 和任务标识；新增后回读、修改和取消都核对原对象。修改要带最新 revision 与实际内容 tag，外部变化不会被旧编辑覆盖。只改标题保留原重复规则与提醒设置。提供首次日历授权入口，不会在后台弹出权限窗口。

时钟没有通用对象 ID；保留创建操作的来源指纹和时间、名称、重复日期等定位信息。修改或取消只定位原闹钟，不创建替代项。当前获准时钟界面的新鲜观察只有在目标唯一、可读且满足核对条件时才机器核验；否则显示待核对或用户确认。取消安排可交给小云继续处理原项。无法定位不会假称成功。

**小云后台计划**通过 WorkManager 到点运行独立 Flutter 引擎；一次、每天、每周和固定间隔（至少 15 分钟）均支持。它适合整理、生成内容、管理待办以及已支持的无界面设备能力。实际触发允许 Android 延迟；需要精确提醒应使用系统日历/时钟。

- 后台不启动 Activity，不打开其他软件，不创建常驻前台服务。结果通知只有用户点击才打开对应任务。
- 整理模式允许返回生成内容；管理待办必须取得实际修改回执；手机动作必须取得真实设备写操作核验回执。文字回答不能冒充操作完成。
- 后台设备能力目前限状态、亮度读取/修改并检查现有权限；UI 操作显示等待条件，不在锁屏或缺少授权时尝试开软件。
- 计划有已启用、已暂停、已结束、待配置；每次触发独立记录处理中、已完成、待核对、未完成、已跳过、等待条件。重复计划完成一轮后继续安排下一轮。
- 暂停/修改/取消使旧租约失效，归档任务在同一数据库事务中暂停其计划；移出管理记录不默默删除系统提醒。“取消全部安排”同时停止本地计划并处理关联的系统对象，无法确认的外部结果仍为待核对。

## 持久化与执行保护

Android 使用同一个 SQLite 数据库，前台与后台通过事务和版本 CAS 更新，避免互相覆盖。首次迁移保存原个人空间 JSON 到迁移备份，兼容 v1/v2，原偏好副本及记忆内容保留。旧日期不生成计划。非 Android 的存储保留原兼容路径。

每轮由“计划 ID + 触发时间”确定唯一执行编号。先事务领取租约、先记录写入指纹、先预留模型用量，再发出请求。重复触发不重复执行，同一天中断的未知结果不自动重放；后续合法重复仍是新的一轮。进程死亡、超时和停止后保留待核对结果，不通过重做来核对。原创建编号也保留在对象中，不因有限回执表裁剪而重新创建已结束计划或已取消提醒。

后台恢复支持重启、应用更新、时间和时区变化。每日/每周规则按保存的时区或跟随设备时区，包含夏令时处理。错过时可跳过，或在设定窗口内只处理最近一次；不积压补跑所有漏掉的轮次。用户强制停止应用及系统后台限制仍由 Android 控制，重新打开应用时重新核对调度。

计划固定保存所选模型的公开配置和凭据引用，不保存密钥/登录令牌。普通聊天换模型不会改变已有计划；模型配置、密钥引用或账户身份变化时等待重新绑定。执行结果仅保存最近一次有限长度结果及必要私有回执，不复制聊天、截图或完整工具树。

模型每次最多 1–5 个请求、每天每计划最多 20 个、全部计划合计每天最多 40 个；每次输出 512–4096 tokens。预算在 HTTP 之前提交，中断仍计已预留用量；达到上限暂停等待处理，不自动无限重试。

## 验证

自动化覆盖旧数据迁移、前后台 CAS、过期编辑、幂等完成、计划租约、唯一触发、合法重复、未知中断、归档暂停、预算、错过时间、夏令时、无界面能力拒绝，以及真实 Calendar Provider 新增/修改/取消。独立 Android QA 包执行真实 WorkManager 后台、重复、暂停恢复、模型固定及重启恢复；受控模型仅访问本机 HTTP。真实手机发布包另外验收，结果以本次交接和验收收据为准。

依赖 WorkManager 2.11.2，包含 Android 15+ 后台网络约束修复。参考：[WorkManager 发布说明](https://developer.android.com/jetpack/androidx/releases/work)、[持久后台工作](https://developer.android.com/develop/background-work/background-tasks/persistent/getting-started/define-work)、[系统日历](https://developer.android.com/identity/providers/calendar-provider)。
