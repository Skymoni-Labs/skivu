# 星尘成云启动动画

开屏在本地状态恢复后播放一次，沿用 Skivu 已批准的云朵图形，不使用图标的黑色方形底板或额外品牌文字。粒子成云后直接缩小落位并淡出，实际聊天页的顶栏与输入框依次描亮，没有在控件之间飞行的光点或拖尾。

默认时长 2800ms，聚合与成云约占前一秒；落位 1064—1932ms，顶栏唤醒 1456—2212ms，输入框唤醒 1792—2716ms。阶段适度交叠，不插入固定停顿。描边按实际控件的周长匹配速度，使用用户配置的圆角、位置和主题强调色，不生成示意聊天内容。

经典聊天界面分别渐显实际顶栏、消息和输入框。QQ / 微信界面插件整体渐显，保留插件自己的布局；不在插件上叠加假的经典控件。动画完成后保留同一页面状态，后台返回不重播；系统或外观配置的“减少动态效果”直接跳过。装饰资源加载失败不会阻断启动，启动更新提示延后到动画结束且 App 回到前台后显示。

实际玻璃始终完整绘制，渐显通过壁纸纹理遮罩完成，不向 `BackdropFilter` 外包裹逐帧 `Opacity`，避免 Android 玻璃在启动中出现黑边。静态壁纸遮罩沿用现有壁纸采样，既不复制聊天画面，也不采集敏感内容；视频背景没有静态采样时保留全局退场和边缘唤醒。

云朵透明遮罩与 420 个粒子落点由 `scripts/generate_launch_cloud.py` 从 `assets/branding/skivu-approved.png` 派生，原始图标文件不变。开屏逻辑和素材适配独立编写，没有引入第三方动画运行库。此功能不修改聊天数据、模型权限或服务器的模型发布守卫。
